SKYNETUG HERO IMAGE
===================

Save the hero mockup image (the person using the computer) as:

  hero-mockup.png

In this directory:
  c:\wamp64\www\Skynetug Webhosting\skynetug\public\images\hero-mockup.png

The homepage will automatically display it in the right column of the hero section.

Recommended image specs:
  - Filename: hero-mockup.png  (or .jpg / .webp — update the src in home.blade.php if different)
  - Width: 1040px or original resolution
  - The image will be displayed at max-width: 560px with rounded corners and a drop shadow

If the image file is missing, the hero right column is hidden on mobile 
and shows a placeholder box on desktop until you add the file.
